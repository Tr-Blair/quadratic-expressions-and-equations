    Problem 39 Checkpoint 2.1.1, Question 1.

    State the degree of \(7x - 2\) and hence state whether it is a quadratic expression.
    🔗
    Solution.
    The highest power of \(x\) is \(1\text{,}\) so the degree is \(1\text{.}\) It is a linear expression, so it is not quadratic.
    🔗

    Problem 40 Checkpoint 2.1.1, Question 2.

    State the degree of \(4x^2 + 3\) and hence state whether it is a quadratic expression.
    🔗
    Solution.
    The highest power of \(x\) is \(2\text{,}\) so the degree is \(2\text{.}\) It is a quadratic expression (here \(b = 0\)).
    🔗

    Problem 41 Checkpoint 2.1.1, Question 3.

    State the degree of \(5 - x^3\) and hence state whether it is a quadratic expression.
    🔗
    Solution.
    The highest power of \(x\) is \(3\text{,}\) so the degree is \(3\text{.}\) It is a cubic expression, so it is not quadratic.

    Problem 42 Checkpoint 2.1.1, Question 4.

    State the degree of \(x^2 + x + 3\) and hence state whether it is a quadratic expression.
    🔗
    Solution.
    The highest power of \(x\) is \(2\text{,}\) so the degree is \(2\text{.}\) It is a quadratic expression.

    Problem 43 Checkpoint 2.1.7, Question 1.

    Form a quadratic expression for the product of \((x-3)\) and \((2x+1)\text{.}\)
    🔗
    Solution.
    \begin{align*} (x-3)(2x+1) \amp = 2x^2 + x - 6x - 3\\ \amp = 2x^2 - 5x - 3 \end{align*}
    🔗
    🔗

    Problem 44 Checkpoint 2.1.7, Question 2.

    A rectangular room has length \((3x+2)\) metres and breadth \((x-1)\) metres. Write an expression for its area.
    🔗
    Solution.
    \begin{align*} \text{Area} \amp = (3x+2)(x-1)\\ \amp = 3x^2 - 3x + 2x - 2\\ \amp = 3x^2 - x - 2 \end{align*}
    The area is \((3x^2 - x - 2)\,\text{m}^2\text{.}\)
    🔗
    🔗
    🔗

    Problem 45 Checkpoint 2.1.7, Question 3.

    Form an expression for the sum of the squares of two consecutive even numbers, \(n\) and \(n+2\text{.}\)
    🔗
    Solution.
    \begin{align*} n^2 + (n+2)^2 \amp = n^2 + n^2 + 4n + 4\\ \amp = 2n^2 + 4n + 4 \end{align*}
    🔗
    🔗

    Problem 46 Checkpoint 2.1.7, Question 4.

    A trader sells \(x\) items at a price of \((80-x)\) shillings each. Form an expression for the total income.
    🔗
    Solution.
    \begin{align*} \text{Income} \amp = x(80-x)\\ \amp = 80x - x^2 \end{align*}
    The total income is \((80x - x^2)\) shillings.
    🔗
    🔗
    🔗

    Problem 47 Checkpoint 2.1.7, Question 5.

    A rectangular field has length \((2x+1)\) metres and width \((x+3)\) metres. Write its area, then find the area when \(x=5\text{.}\)
    🔗
    Solution.
    \begin{align*} \text{Area} \amp = (2x+1)(x+3)\\ \amp = 2x^2 + 6x + x + 3\\ \amp = 2x^2 + 7x + 3 \end{align*}
    When \(x=5\text{:}\)
    🔗
    \begin{align*} 2(5)^2 + 7(5) + 3 \amp = 50 + 35 + 3 = 88 \end{align*}
    The area is \(88\,\text{m}^2\text{.}\)
    🔗

    Section Checkpoints: Quadratic Identities

    Problem 48 Checkpoint 2.2.8, Question 1(a).

    Expand \((x+6)^2\text{.}\)
    🔗
    Solution.
    Using \((a+b)^2 = a^2 + 2ab + b^2\) with \(a=x\) and \(b=6\text{:}\)
    🔗
    \begin{align*} (x+6)^2 \amp = x^2 + 2(x)(6) + 6^2\\ \amp = x^2 + 12x + 36 \end{align*}
    🔗
    🔗

    Problem 49 Checkpoint 2.2.8, Question 1(b).

    Expand \((5x-2)^2\text{.}\)
    🔗
    Solution.
    Using \((a-b)^2 = a^2 - 2ab + b^2\) with \(a=5x\) and \(b=2\text{:}\)
    🔗
    \begin{align*} (5x-2)^2 \amp = (5x)^2 - 2(5x)(2) + 2^2\\ \amp = 25x^2 - 20x + 4 \end{align*}
    🔗
    🔗

    Problem 50 Checkpoint 2.2.8, Question 1(c).

    Expand \((4x+3)(4x-3)\text{.}\)
    🔗
    Solution.
    Using \((a+b)(a-b) = a^2 - b^2\) with \(a=4x\) and \(b=3\text{:}\)
    🔗
    \begin{align*} (4x+3)(4x-3) \amp = (4x)^2 - 3^2\\ \amp = 16x^2 - 9 \end{align*}
    🔗
    🔗

    Problem 51 Checkpoint 2.2.8, Question 1(d).

    Expand \((2a-3b)^2\text{.}\)
    🔗
    Solution.
    Using \((a-b)^2 = a^2 - 2ab + b^2\) with first term \(2a\) and second term \(3b\text{:}\)
    🔗
    \begin{align*} (2a-3b)^2 \amp = (2a)^2 - 2(2a)(3b) + (3b)^2\\ \amp = 4a^2 - 12ab + 9b^2 \end{align*}
    🔗
    🔗

    Problem 52 Checkpoint 2.2.8, Question 2(a).

    Factorise \(x^2 - 64\text{.}\)
    🔗
    Solution.
    This is a difference of two squares, \(a^2 - b^2 = (a+b)(a-b)\text{,}\) with \(a=x\) and \(b=8\text{:}\)
    🔗
    \begin{align*} x^2 - 64 \amp = x^2 - 8^2\\ \amp = (x+8)(x-8) \end{align*}
    🔗
    🔗

    Problem 53 Checkpoint 2.2.8, Question 2(b).

    Factorise \(9x^2 + 12x + 4\text{.}\)
    🔗
    Solution.
    Notice \(9x^2 = (3x)^2\text{,}\) \(4 = 2^2\) and \(12x = 2(3x)(2)\text{.}\) This matches \((a+b)^2 = a^2 + 2ab + b^2\text{:}\)
    🔗
    \begin{align*} 9x^2 + 12x + 4 \amp = (3x)^2 + 2(3x)(2) + 2^2\\ \amp = (3x+2)^2 \end{align*}
    🔗
    🔗

    Problem 54 Checkpoint 2.2.8, Question 2(c).

    Factorise \(36x^2 - 60x + 25\text{.}\)
    🔗
    Solution.
    Notice \(36x^2 = (6x)^2\text{,}\) \(25 = 5^2\) and \(60x = 2(6x)(5)\text{.}\) This matches \((a-b)^2 = a^2 - 2ab + b^2\text{:}\)
    🔗
    \begin{align*} 36x^2 - 60x + 25 \amp = (6x)^2 - 2(6x)(5) + 5^2\\ \amp = (6x-5)^2 \end{align*}
    🔗
    🔗
    🔗

    Section Checkpoints: Quadratic Equations

    Problem 55 Checkpoint 2.3.3, Question 1.

    The area of a rectangular plot is \(528\,\text{m}^2\text{.}\) The length of the plot (in metres) is one more than twice its breadth. Find the length and breadth of the plot.
    🔗
    Solution.
    Let the breadth be \(b\) metres. Then the length is \((2b+1)\) metres.
    🔗
    \begin{align*} b(2b+1) \amp = 528\\ 2b^2 + b - 528 \amp = 0\\ (b-16)(2b+33) \amp = 0 \end{align*}
    So \(b = 16\) or \(b = -\frac{33}{2}\text{.}\) A length cannot be negative, so we reject \(b = -\frac{33}{2}\text{.}\)
    🔗
    The breadth is \(16\) m and the length is \(2(16)+1 = 33\) m.
    🔗
    🔗
    🔗

    Problem 56 Checkpoint 2.3.3, Question 2.

    The product of two consecutive positive integers is \(306\text{.}\) Find the integers.
    🔗
    Solution.
    Let the integers be \(n\) and \(n+1\text{.}\)
    🔗
    \begin{align*} n(n+1) \amp = 306\\ n^2 + n - 306 \amp = 0\\ (n-17)(n+18) \amp = 0 \end{align*}
    So \(n = 17\) or \(n = -18\text{.}\) The integers are positive, so \(n = 17\text{.}\) The integers are \(17\) and \(18\text{.}\)
    🔗
    🔗
    🔗

    Problem 57 Checkpoint 2.3.3, Question 3.

    Rohan’s mother is \(26\) years older than him. The product of their ages (in years) \(3\) years from now will be \(360\text{.}\) Find Rohan’s present age.
    🔗
    Solution.
    Let Rohan’s present age be \(x\) years. His mother’s present age is \((x+26)\) years. In \(3\) years their ages will be \((x+3)\) and \((x+29)\text{.}\)
    🔗
    \begin{align*} (x+3)(x+29) \amp = 360\\ x^2 + 32x + 87 \amp = 360\\ x^2 + 32x - 273 \amp = 0\\ (x-7)(x+39) \amp = 0 \end{align*}
    So \(x = 7\) or \(x = -39\text{.}\) An age cannot be negative, so Rohan is \(7\) years old.
    🔗
    Check: \((7+3)(7+29) = 10 \times 36 = 360\text{.}\)
    🔗
    🔗
    🔗

    Problem 58 Checkpoint 2.3.11, Question 1.

    Solve \(x^2 - 9x + 20 = 0\) by factorization.
    🔗
    Solution.
    Two numbers that multiply to \(20\) and add to \(-9\) are \(-4\) and \(-5\text{.}\)
    🔗
    \begin{align*} x^2 - 9x + 20 \amp = 0\\ (x-4)(x-5) \amp = 0 \end{align*}
    So \(x - 4 = 0\) or \(x - 5 = 0\text{,}\) giving \(x = 4\) or \(x = 5\text{.}\)
    🔗
    🔗
    🔗

    Problem 59 Checkpoint 2.3.11, Question 2.

    Solve \(x^2 + 8x - 9 = 0\) by completing the square.
    🔗
    Solution.
    Move the constant to the right side:
    🔗
    \begin{align*} x^2 + 8x \amp = 9 \end{align*}
    Add \(\left(\frac{8}{2}\right)^2 = 16\) to both sides:
    🔗
    \begin{align*} x^2 + 8x + 16 \amp = 9 + 16\\ (x+4)^2 \amp = 25\\ x + 4 \amp = \pm 5 \end{align*}
    So \(x = -4 + 5 = 1\) or \(x = -4 - 5 = -9\text{.}\)
    🔗
    🔗
    🔗

    Problem 60 Checkpoint 2.3.11, Question 3.

    Solve \(3x^2 + 5x - 2 = 0\) using the quadratic formula.
    🔗
    Solution.
    Here \(a = 3\text{,}\) \(b = 5\) and \(c = -2\text{.}\)
    🔗
    \begin{align*} x \amp = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\\ \amp = \frac{-5 \pm \sqrt{5^2 - 4(3)(-2)}}{2(3)}\\ \amp = \frac{-5 \pm \sqrt{49}}{6}\\ \amp = \frac{-5 \pm 7}{6} \end{align*}
    So \(x = \frac{-5+7}{6} = \frac{1}{3}\) or \(x = \frac{-5-7}{6} = -2\text{.}\)
    🔗
    🔗
    🔗

    Problem 61 Checkpoint 2.3.11, Question 4.

    Solve \(2x^2 + 7x = 15\) by factorization.
    🔗
    Solution.
    Write in standard form: \(2x^2 + 7x - 15 = 0\text{.}\) Here \(ac = 2 \times (-15) = -30\text{,}\) and two numbers that multiply to \(-30\) and add to \(7\) are \(10\) and \(-3\text{.}\)
    🔗
    \begin{align*} 2x^2 + 10x - 3x - 15 \amp = 0\\ 2x(x+5) - 3(x+5) \amp = 0\\ (2x-3)(x+5) \amp = 0 \end{align*}
    So \(x = \frac{3}{2}\) or \(x = -5\text{.}\)
    🔗
    🔗
    🔗

    Problem 62 Checkpoint 2.3.11, Question 5.

    Solve \(x^2 - 6x - 16 = 0\) by completing the square.
    🔗
    Solution.
    Move the constant to the right side:
    🔗
    \begin{align*} x^2 - 6x \amp = 16 \end{align*}
    Add \(\left(\frac{-6}{2}\right)^2 = 9\) to both sides:
    🔗
    \begin{align*} x^2 - 6x + 9 \amp = 16 + 9\\ (x-3)^2 \amp = 25\\ x - 3 \amp = \pm 5 \end{align*}
    So \(x = 3 + 5 = 8\) or \(x = 3 - 5 = -2\text{.}\)
    🔗
    🔗
    🔗

    Problem 63 Checkpoint 2.3.11, Question 6.

    Solve \(2x^2 - 7x + 3 = 0\) using the quadratic formula.
    🔗
    Solution.
    Here \(a = 2\text{,}\) \(b = -7\) and \(c = 3\text{.}\)
    🔗
    \begin{align*} x \amp = \frac{-(-7) \pm \sqrt{(-7)^2 - 4(2)(3)}}{2(2)}\\ \amp = \frac{7 \pm \sqrt{25}}{4}\\ \amp = \frac{7 \pm 5}{4} \end{align*}
    So \(x = \frac{12}{4} = 3\) or \(x = \frac{2}{4} = \frac{1}{2}\text{.}\)
    🔗
    🔗
    🔗

    Problem 64 Checkpoint 2.3.11, Question 7.

    The length of a rectangular lawn is \(5\) metres longer than its width. If the area of the lawn is \(84\,\text{m}^2\text{,}\) calculate its length and width by factorization.
    🔗
    Solution.
    Let the width be \(w\) metres. Then the length is \((w+5)\) metres.
    🔗
    \begin{align*} w(w+5) \amp = 84\\ w^2 + 5w - 84 \amp = 0\\ (w+12)(w-7) \amp = 0 \end{align*}
    So \(w = -12\) or \(w = 7\text{.}\) Width must be positive, so we reject \(w = -12\text{.}\)
    🔗
    The width is \(7\) m and the length is \(7 + 5 = 12\) m.
    🔗
    🔗
    🔗

    Problem 65 Checkpoint 2.3.11, Question 8.

    The product of two consecutive positive integers is \(156\text{.}\) Set up a quadratic equation and solve it by completing the square to find the two integers.
    🔗
    Solution.
    Let the integers be \(n\) and \(n+1\text{.}\)
    🔗
    \begin{align*} n(n+1) \amp = 156\\ n^2 + n \amp = 156 \end{align*}
    Add \(\left(\frac{1}{2}\right)^2 = \frac{1}{4}\) to both sides:
    🔗
    \begin{align*} n^2 + n + \frac{1}{4} \amp = 156 + \frac{1}{4}\\ \left(n + \frac{1}{2}\right)^2 \amp = \frac{625}{4}\\ n + \frac{1}{2} \amp = \pm \frac{25}{2} \end{align*}
    So \(n = 12\) or \(n = -13\text{.}\) The integers are positive, so \(n = 12\text{.}\) The integers are \(12\) and \(13\text{.}\)
    🔗
    🔗
    🔗

    Problem 66 Checkpoint 2.3.11, Question 9.

    A ball is kicked vertically upwards into the air. Its height \(h\) (in metres) after \(t\) seconds is given by \(h = 20t - 5t^2\text{.}\) Find the time(s) when the ball reaches a height of \(15\) metres using the quadratic formula.
    🔗
    Solution.
    Set \(h = 15\text{:}\)
    🔗
    \begin{align*} 20t - 5t^2 \amp = 15\\ 5t^2 - 20t + 15 \amp = 0\\ t^2 - 4t + 3 \amp = 0 \end{align*}
    Here \(a = 1\text{,}\) \(b = -4\) and \(c = 3\text{.}\)
    🔗
    \begin{align*} t \amp = \frac{4 \pm \sqrt{(-4)^2 - 4(1)(3)}}{2(1)}\\ \amp = \frac{4 \pm \sqrt{4}}{2}\\ \amp = \frac{4 \pm 2}{2} \end{align*}
    So \(t = 1\) or \(t = 3\text{.}\) The ball is at \(15\) m after \(1\) second (going up) and again after \(3\) seconds (coming down).
    🔗
    🔗
    🔗

    Problem 67 Checkpoint 2.3.11, Question 10.

    The hypotenuse of a right-angled triangle is \((x+2)\) cm. The other two sides are \(x\) cm and \((x-2)\) cm. Use Pythagoras’ Theorem to form a quadratic equation and solve for \(x\text{.}\)
    🔗
    Solution.
    By Pythagoras’ Theorem:
    🔗
    \begin{align*} x^2 + (x-2)^2 \amp = (x+2)^2\\ x^2 + x^2 - 4x + 4 \amp = x^2 + 4x + 4\\ x^2 - 8x \amp = 0\\ x(x-8) \amp = 0 \end{align*}
    So \(x = 0\) or \(x = 8\text{.}\) A side length cannot be \(0\text{,}\) so \(x = 8\text{.}\)
    🔗
    The sides are \(6\) cm, \(8\) cm and \(10\) cm, and indeed \(6^2 + 8^2 = 100 = 10^2\text{.}\)
