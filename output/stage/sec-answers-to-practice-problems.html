    Problem 68 Practice Exercise 1: The Vegetable Garden.

    The length of a rectangular vegetable garden is \(3\) metres more than its width. The area of the garden is \(70\,\text{m}^2\text{.}\) Find the length and width of the garden.
    🔗
    Solution.
    Let the width be \(w\) metres. Then the length is \((w+3)\) metres.
    🔗
    \begin{align*} w(w+3) \amp = 70\\ w^2 + 3w - 70 \amp = 0\\ (w+10)(w-7) \amp = 0 \end{align*}
    So \(w = -10\) or \(w = 7\text{.}\) A width cannot be negative, so \(w = 7\text{.}\)
    🔗
    The width is \(7\) m and the length is \(10\) m. Check: \(7 \times 10 = 70\text{.}\)
    🔗
    🔗
    🔗

    Problem 69 Practice Exercise 2: Consecutive Odd Numbers.

    The product of two consecutive positive odd integers is \(143\text{.}\) Form a quadratic equation and solve it to find the integers.
    🔗
    Solution.
    Let the integers be \(n\) and \(n+2\text{.}\)
    🔗
    \begin{align*} n(n+2) \amp = 143\\ n^2 + 2n - 143 \amp = 0\\ (n+13)(n-11) \amp = 0 \end{align*}
    So \(n = -13\) or \(n = 11\text{.}\) The integers are positive, so \(n = 11\text{.}\)
    🔗
    The integers are \(11\) and \(13\text{.}\) Check: \(11 \times 13 = 143\text{.}\)
    🔗
    🔗

      🔗
      \begin{align*} 103^2 - 97^2 \amp = (103+97)(103-97)\\ \amp = 200 \times 6\\ \amp = 1200 \end{align*}

    Problem 71 Practice Exercise 4: The Maize Plot.

    A farmer has a rectangular maize plot with a perimeter of \(34\) m and an area of \(60\,\text{m}^2\text{.}\) Find the dimensions of the plot.
    🔗
    Solution.
    The perimeter is \(34\) m, so length plus width is \(17\) m. Let the width be \(w\) metres. Then the length is \((17-w)\) metres.
    🔗
    \begin{align*} w(17-w) \amp = 60\\ 17w - w^2 \amp = 60\\ w^2 - 17w + 60 \amp = 0\\ (w-5)(w-12) \amp = 0 \end{align*}
    So \(w = 5\) or \(w = 12\text{.}\) If \(w = 5\) the length is \(12\text{,}\) and if \(w = 12\) the length is \(5\text{.}\) Both give the same plot.
    🔗
    The plot measures \(12\) m by \(5\) m. Check: perimeter \(2(12+5) = 34\) and area \(12 \times 5 = 60\text{.}\)
    🔗
    🔗

    Problem 72 Practice Exercise 5: The Matatu Journey.

    A matatu travels a distance of \(120\) km at a uniform speed. If its speed had been \(10\) km/h more, the journey would have taken \(1\) hour less. Find the original speed of the matatu.
    🔗
    Solution.
    Let the original speed be \(x\) km/h. Using time \(= \frac{\text{distance}}{\text{speed}}\text{,}\) the original time is \(\frac{120}{x}\) hours and the new time is \(\frac{120}{x+10}\) hours. The difference is \(1\) hour:
    🔗
    \begin{align*} \frac{120}{x} - \frac{120}{x+10} \amp = 1\\ 120(x+10) - 120x \amp = x(x+10)\\ 1200 \amp = x^2 + 10x\\ x^2 + 10x - 1200 \amp = 0\\ (x+40)(x-30) \amp = 0 \end{align*}
    So \(x = -40\) or \(x = 30\text{.}\) A speed cannot be negative, so the original speed is \(30\) km/h.
    🔗
    Check: \(\frac{120}{30} = 4\) hours and \(\frac{120}{40} = 3\) hours, which is \(1\) hour less.
    🔗
    🔗
    🔗

    Problem 73 Practice Exercise 6: The Right-Angled Triangle.

    The two shorter sides of a right-angled triangle differ by \(7\) cm. The hypotenuse is \(13\) cm. Form a quadratic equation and use it to find the lengths of the two shorter sides.
    🔗
    Solution.
    Let the shorter side be \(x\) cm. Then the other side is \((x+7)\) cm. By Pythagoras’ Theorem:
    🔗
    \begin{align*} x^2 + (x+7)^2 \amp = 13^2\\ x^2 + x^2 + 14x + 49 \amp = 169\\ 2x^2 + 14x - 120 \amp = 0\\ x^2 + 7x - 60 \amp = 0\\ (x+12)(x-5) \amp = 0 \end{align*}
    So \(x = -12\) or \(x = 5\text{.}\) A length cannot be negative, so \(x = 5\text{.}\)
    🔗
    The two shorter sides are \(5\) cm and \(12\) cm. Check: \(5^2 + 12^2 = 169 = 13^2\text{.}\)
    🔗
    🔗
    🔗

    Problem 74 Practice Exercise 7: The Exercise Books.

    A school buys some exercise books for exactly Ksh \(600\text{.}\) If each book had cost Ksh \(5\) less, the school would have bought \(4\) more books for the same amount of money. How many books did the school buy, and what was the price of each book?
    🔗
    Solution.
    Let the number of books be \(n\text{.}\) The price of each book is \(\frac{600}{n}\) shillings. With the lower price, the school buys \((n+4)\) books at \(\left(\frac{600}{n} - 5\right)\) shillings each, still spending \(600\) shillings:
    🔗
    \begin{align*} (n+4)\left(\frac{600}{n} - 5\right) \amp = 600\\ 600 - 5n + \frac{2400}{n} - 20 \amp = 600\\ -5n + \frac{2400}{n} - 20 \amp = 0\\ -5n^2 - 20n + 2400 \amp = 0\\ n^2 + 4n - 480 \amp = 0\\ (n+24)(n-20) \amp = 0 \end{align*}
    So \(n = -24\) or \(n = 20\text{.}\) The number of books cannot be negative, so \(n = 20\text{.}\)
    🔗
    The school bought \(20\) books at Ksh \(\frac{600}{20} = 30\) each. Check: \(24\) books at Ksh \(25\) each cost \(24 \times 25 = 600\text{.}\)
    🔗
    🔗
    🔗

    Problem 75 Practice Exercise 8: The Stone from the Cliff.

    A stone is thrown upwards from the top of a \(25\) m cliff. Its height \(h\) metres above the ground after \(t\) seconds is given by \(h = 25 + 20t - 5t^2\text{.}\)
    🔗
    1. Use the quadratic formula to find when the stone hits the ground.
      🔗
      🔗
    2. Find the times when the stone is at a height of \(40\) m.
      🔗
      🔗
    3. Complete the square to find the maximum height of the stone.
      🔗
      🔗
    Solution.
    1. The stone is on the ground when \(h = 0\text{:}\)
      🔗
      \begin{align*} 25 + 20t - 5t^2 \amp = 0\\ t^2 - 4t - 5 \amp = 0 \end{align*}
      Here \(a = 1\text{,}\) \(b = -4\) and \(c = -5\text{:}\)
      🔗
      \begin{align*} t \amp = \frac{4 \pm \sqrt{(-4)^2 - 4(1)(-5)}}{2}\\ \amp = \frac{4 \pm \sqrt{36}}{2}\\ \amp = \frac{4 \pm 6}{2} \end{align*}
      So \(t = 5\) or \(t = -1\text{.}\) Time cannot be negative, so the stone hits the ground after \(5\) seconds.
      🔗
      🔗
    2. Put \(h = 40\text{:}\)
      🔗
      \begin{align*} 25 + 20t - 5t^2 \amp = 40\\ 5t^2 - 20t + 15 \amp = 0\\ t^2 - 4t + 3 \amp = 0\\ (t-1)(t-3) \amp = 0 \end{align*}
      The stone is at \(40\) m after \(1\) second (going up) and after \(3\) seconds (coming down).
      🔗
      🔗
    3. Complete the square:
      🔗
      \begin{align*} h \amp = -5t^2 + 20t + 25\\ \amp = -5(t^2 - 4t) + 25\\ \amp = -5\left[(t-2)^2 - 4\right] + 25\\ \amp = 45 - 5(t-2)^2 \end{align*}
      Since \(5(t-2)^2 \ge 0\text{,}\) the largest value of \(h\) is \(45\text{,}\) reached when \(t = 2\text{.}\) The maximum height is \(45\) m.
      🔗
      🔗
    🔗
    🔗

    Problem 76 Practice Exercise 9: The Path Around the Garden.

    A rectangular flower garden measures \(12\) m by \(8\) m. A path of uniform width \(x\) metres is built all the way around it. The total area of the garden and the path together is \(165\,\text{m}^2\text{.}\) Form a quadratic equation and use the quadratic formula to find the width of the path.
    🔗
    Solution.
    With the path, the length becomes \((12 + 2x)\) m and the width becomes \((8 + 2x)\) m.
    🔗
    \begin{align*} (12+2x)(8+2x) \amp = 165\\ 96 + 24x + 16x + 4x^2 \amp = 165\\ 4x^2 + 40x - 69 \amp = 0 \end{align*}
    Here \(a = 4\text{,}\) \(b = 40\) and \(c = -69\text{:}\)
    🔗
    \begin{align*} x \amp = \frac{-40 \pm \sqrt{40^2 - 4(4)(-69)}}{2(4)}\\ \amp = \frac{-40 \pm \sqrt{2704}}{8}\\ \amp = \frac{-40 \pm 52}{8} \end{align*}
    So \(x = \frac{12}{8} = 1.5\) or \(x = -\frac{92}{8} = -11.5\text{.}\) A width cannot be negative, so the path is \(1.5\) m wide.
    🔗
    Check: \((12+3)(8+3) = 15 \times 11 = 165\text{.}\)
    🔗
    🔗
    🔗

    Problem 77 Practice Exercise 10: Fencing Against a Wall.

    A farmer has \(40\) m of fencing. She uses it to fence three sides of a rectangular paddock. The fourth side is an existing wall that needs no fencing. The area of the paddock is \(150\,\text{m}^2\text{.}\) Find the possible dimensions of the paddock.
    🔗
    Solution.
    Let the two sides at right angles to the wall be \(x\) metres each. The side parallel to the wall is then \((40 - 2x)\) metres.
    🔗
    \begin{align*} x(40 - 2x) \amp = 150\\ 40x - 2x^2 \amp = 150\\ 2x^2 - 40x + 150 \amp = 0\\ x^2 - 20x + 75 \amp = 0\\ (x-5)(x-15) \amp = 0 \end{align*}
    So \(x = 5\) or \(x = 15\text{.}\) Both values are possible:
    🔗
    • If \(x = 5\text{,}\) the sides at right angles to the wall are \(5\) m and the side along the wall is \(30\) m.
      🔗
      🔗
    • If \(x = 15\text{,}\) the sides at right angles to the wall are \(15\) m and the side along the wall is \(10\) m.
      🔗
      🔗
    Check: \(5 \times 30 = 150\) and \(15 \times 10 = 150\text{.}\)
    🔗
    🔗

    Problem 78 Olympiad Problem 1: A Parameter in the Equation.

    Consider the equation \(x^2 - (k+2)x + 2k = 0\text{,}\) where \(k\) is a real number.
    🔗
    1. Factorise the left-hand side and hence solve the equation in terms of \(k\text{.}\)
      🔗
      🔗
    2. Show that the discriminant is a perfect square for every value of \(k\text{,}\) so the equation always has real roots.
      🔗
      🔗
    3. Find the value of \(k\) for which the equation has exactly one root.
      🔗
      🔗
    Solution.
    1. \begin{align*} x^2 - (k+2)x + 2k \amp = x^2 - kx - 2x + 2k\\ \amp = x(x-k) - 2(x-k)\\ \amp = (x-2)(x-k) \end{align*}
      So the roots are \(x = 2\) and \(x = k\text{.}\)
      🔗
      🔗
    2. \begin{align*} \Delta \amp = (k+2)^2 - 4(1)(2k)\\ \amp = k^2 + 4k + 4 - 8k\\ \amp = k^2 - 4k + 4\\ \amp = (k-2)^2 \end{align*}
      Since \((k-2)^2 \ge 0\) for every real \(k\text{,}\) the discriminant is never negative, so the roots are always real.
      🔗
      🔗
    3. There is exactly one root when \(\Delta = 0\text{,}\) that is \((k-2)^2 = 0\text{,}\) so \(k = 2\text{.}\) Then the roots \(2\) and \(k\) coincide, and the only root is \(x = 2\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Problem 79 Olympiad Problem 2: A Hidden Quadratic.

    Solve \((x^2 - 5x)^2 - 2(x^2 - 5x) - 24 = 0\text{.}\)
    🔗
    Solution.
    Let \(y = x^2 - 5x\text{.}\) The equation becomes a quadratic in \(y\text{:}\)
    🔗
    \begin{align*} y^2 - 2y - 24 \amp = 0\\ (y-6)(y+4) \amp = 0 \end{align*}
    So \(y = 6\) or \(y = -4\text{.}\) Now substitute back.
    🔗
    Case 1: \(x^2 - 5x = 6\text{.}\)
    🔗
    \begin{align*} x^2 - 5x - 6 \amp = 0\\ (x-6)(x+1) \amp = 0 \end{align*}
    So \(x = 6\) or \(x = -1\text{.}\)
    🔗
    Case 2: \(x^2 - 5x = -4\text{.}\)
    🔗
    \begin{align*} x^2 - 5x + 4 \amp = 0\\ (x-1)(x-4) \amp = 0 \end{align*}
    So \(x = 1\) or \(x = 4\text{.}\)
    🔗
    The equation has four solutions: \(x = -1,\ 1,\ 4,\ 6\text{.}\)
    🔗
    Check with \(x = 1\text{:}\) \(x^2 - 5x = -4\text{,}\) and \((-4)^2 - 2(-4) - 24 = 16 + 8 - 24 = 0\text{.}\)
    🔗
    🔗
    🔗

    Problem 80 Olympiad Problem 3: A Number and Its Reciprocal.

    A non-zero number \(x\) satisfies \(x + \frac{1}{x} = 4\text{.}\)
    🔗
    1. Find the value of \(x^2 + \frac{1}{x^2}\text{.}\)
      🔗
      🔗
    2. Find the value of \(x^3 + \frac{1}{x^3}\text{.}\)
      🔗
      🔗
    3. Form a quadratic equation in \(x\) and solve it. Check that your answer agrees with part (a).
      🔗
      🔗
    Solution.
    1. Square both sides of \(x + \frac{1}{x} = 4\text{:}\)
      🔗
      \begin{align*} \left(x + \frac{1}{x}\right)^2 \amp = x^2 + 2 + \frac{1}{x^2}\\ 16 \amp = x^2 + 2 + \frac{1}{x^2} \end{align*}
      So \(x^2 + \frac{1}{x^2} = 14\text{.}\)
      🔗
      🔗
    2. Cube both sides:
      🔗
      \begin{align*} \left(x + \frac{1}{x}\right)^3 \amp = x^3 + 3x + \frac{3}{x} + \frac{1}{x^3}\\ \amp = x^3 + \frac{1}{x^3} + 3\left(x + \frac{1}{x}\right)\\ 64 \amp = x^3 + \frac{1}{x^3} + 12 \end{align*}
      So \(x^3 + \frac{1}{x^3} = 52\text{.}\)
      🔗
      🔗
    3. Multiply \(x + \frac{1}{x} = 4\) by \(x\text{:}\)
      🔗
      \begin{align*} x^2 + 1 \amp = 4x\\ x^2 - 4x + 1 \amp = 0 \end{align*}
      Using the quadratic formula with \(a = 1\text{,}\) \(b = -4\text{,}\) \(c = 1\text{:}\)
      🔗
      \begin{align*} x \amp = \frac{4 \pm \sqrt{16 - 4}}{2}\\ \amp = \frac{4 \pm 2\sqrt{3}}{2}\\ \amp = 2 \pm \sqrt{3} \end{align*}
      Check with \(x = 2 + \sqrt{3}\text{:}\) then \(\frac{1}{x} = 2 - \sqrt{3}\text{,}\) since \((2+\sqrt{3})(2-\sqrt{3}) = 1\text{.}\) Also \(x^2 = 7 + 4\sqrt{3}\) and \(\frac{1}{x^2} = 7 - 4\sqrt{3}\text{,}\) so their sum is \(14\text{,}\) which agrees with part (a).
      🔗
      🔗
    🔗
    🔗

    Problem 81 Olympiad Problem 4: Four Consecutive Integers.

    Prove that the product of any four consecutive integers, plus \(1\text{,}\) is a perfect square. Then use your result to evaluate \(\sqrt{10 \times 11 \times 12 \times 13 + 1}\text{.}\)
    🔗
    Solution.
    Let the four consecutive integers be \(n\text{,}\) \(n+1\text{,}\) \(n+2\) and \(n+3\text{.}\) Pair the first with the last and the middle two:
    🔗
    \begin{align*} n(n+3) \amp = n^2 + 3n\\ (n+1)(n+2) \amp = n^2 + 3n + 2 \end{align*}
    Let \(m = n^2 + 3n\text{.}\) Then:
    🔗
    \begin{align*} n(n+1)(n+2)(n+3) + 1 \amp = m(m+2) + 1\\ \amp = m^2 + 2m + 1\\ \amp = (m+1)^2\\ \amp = (n^2 + 3n + 1)^2 \end{align*}
    This is the square of the integer \(n^2 + 3n + 1\text{,}\) so it is a perfect square.
    🔗
    For \(n = 10\text{:}\) \(n^2 + 3n + 1 = 100 + 30 + 1 = 131\text{.}\) So:
    🔗
    \begin{align*} \sqrt{10 \times 11 \times 12 \times 13 + 1} \amp = 131 \end{align*}
    Check: \(10 \times 11 \times 12 \times 13 = 17160\) and \(131^2 = 17161\text{.}\)
    🔗
    🔗
    🔗

    Problem 82 Olympiad Problem 5: The Largest Possible Area.

    A rectangle has a perimeter of \(20\) cm and an area of \(A\,\text{cm}^2\text{.}\)
    🔗
    1. Let the width be \(x\) cm. Show that \(x^2 - 10x + A = 0\text{.}\)
      🔗
      🔗
    2. Use the discriminant to show that \(A \le 25\text{.}\) What shape is the rectangle when \(A = 25\text{?}\)
      🔗
      🔗
    3. Is it possible for the area to be \(26\,\text{cm}^2\text{?}\) Is it possible for the area to be \(24\,\text{cm}^2\text{?}\) If so, find the dimensions.
      🔗
      🔗
    Solution.
    1. The perimeter is \(20\) cm, so length plus width is \(10\) cm. If the width is \(x\text{,}\) the length is \((10 - x)\text{.}\)
      🔗
      \begin{align*} x(10-x) \amp = A\\ 10x - x^2 \amp = A\\ x^2 - 10x + A \amp = 0 \end{align*}
      🔗
    2. For a rectangle to exist, this equation must have a real solution for \(x\text{,}\) so \(\Delta \ge 0\text{:}\)
      🔗
      \begin{align*} (-10)^2 - 4(1)(A) \amp \ge 0\\ 100 - 4A \amp \ge 0\\ A \amp \le 25 \end{align*}
      When \(A = 25\text{,}\) \(\Delta = 0\) and \(x^2 - 10x + 25 = (x-5)^2 = 0\text{,}\) so \(x = 5\text{.}\) The length is also \(10 - 5 = 5\text{,}\) so the rectangle is a square of side \(5\) cm.
      🔗
      🔗
    3. For \(A = 26\text{:}\) \(\Delta = 100 - 104 = -4 \lt 0\text{,}\) so no such rectangle exists.
      🔗
      For \(A = 24\text{:}\) \(x^2 - 10x + 24 = 0\text{,}\) so \((x-4)(x-6) = 0\text{.}\) The rectangle measures \(4\) cm by \(6\) cm.
      🔗
      🔗
    🔗
    🔗

    Problem 83 Olympiad Problem 6: Integer Roots.

    Find all integer values of \(k\) for which the equation \(x^2 - kx + 24 = 0\) has two integer roots.
    🔗
    Solution.
    Suppose the roots are the integers \(p\) and \(q\text{.}\) Then the equation can be written as:
    🔗
    \begin{align*} (x-p)(x-q) \amp = x^2 - (p+q)x + pq \end{align*}
    Comparing with \(x^2 - kx + 24\text{,}\) we need \(pq = 24\) and \(k = p + q\text{.}\)
    🔗
    List the integer pairs with product \(24\text{,}\) and add each pair:
    🔗
    \((p, q)\) \((1, 24)\) \((2, 12)\) \((3, 8)\) \((4, 6)\)
    \(k = p + q\) \(25\) \(14\) \(11\) \(10\)
    The pairs of negative integers, such as \((-1, -24)\text{,}\) also multiply to \(24\) and give the negatives of these values of \(k\text{.}\)
    🔗
    So \(k \in \{-25, -14, -11, -10, 10, 11, 14, 25\}\text{.}\)
    🔗
    Check with \(k = 10\text{:}\) \(x^2 - 10x + 24 = (x-4)(x-6)\text{,}\) with integer roots \(4\) and \(6\text{.}\)
    🔗
    🔗
