    Subsection Introduction

    We have you studied quadratic expressions of the form \(ax^2 +bx +c, a \neq 0.\) When we equate this expression to zero we get a quadratic equation.
    🔗
    A quadratic equation in the variable \(x\) is an equation of the form \(ax^2 + bx + c = 0\text{,}\) where \(a\text{,}\) \(b\text{,}\) and \(c\) are real numbers and \(a \neq 0\text{.}\)
    🔗
    For example, \(x^2 + x - 30 = 0\) is a quadratic equation. Similarly, \(2x^2 - 3x + 1 = 0\text{,}\) \(4x - 2x^2 + 2 = 0\text{,}\) and \(1 - x^2 + 300 = 0\) are also quadratic equations.
    🔗
    Quadratic equations arise in several situations in the world around us and in different fields of mathematics.
    🔗
    Let us consider a few examples.
    🔗

    Example 22 .

    John and Kamau together have 45 marbles. Both of them lost 5 marbles each, and the product of the number of marbles they now have is 124.
    🔗
    Solution.
    Let the number of marbles John had be \(x\text{.}\)
    🔗
    Then the number of marbles Kamau had is \(45 - x\text{.}\)
    🔗
    After both lose \(5\) marbles each:
    🔗
    • John has: \(x - 5\) marbles
      🔗
      🔗
    • Kamau has: \((45 - x) - 5 = 40 - x\) marbles
      🔗
      🔗
    🔗
    Given that the product of their remaining marbles is \(124\text{:}\)
    🔗
    \begin{align*} (x - 5)(40 - x) \amp = 124\\ 40x - x^2 - 200 + 5x \amp = 124\\ -x^2 + 45x - 324 \amp = 0\\ x^2 - 45x + 324 \amp = 0 \end{align*}
    🔗
    🔗

    Example 23 .

    A train travels a distance of 480 km at a uniform speed. If the speed had been 8 km/h less, then it would have taken 3 hours more to cover the same distance.Find the speed of the train.
    🔗
    Solution.
    Let the original uniform speed of the train be \(x\text{ km/h}\text{.}\)
    🔗
    The distance covered is \(480\text{ km}\text{.}\)
    🔗
    Using the relationship \(\text{Time} = \frac{\text{Distance}}{\text{Speed}}\text{:}\)
    🔗
    • Original time taken: \(t_1 = \frac{480}{x}\text{ hours}\)
      🔗
      🔗
    • Time taken at reduced speed \((x - 8)\text{ km/h}\text{:}\) \(t_2 = \frac{480}{x - 8}\text{ hours}\)
      🔗
      🔗
    🔗
    Given that the time difference is \(3\text{ hours}\text{:}\)
    🔗
    \begin{align*} \frac{480}{x - 8} - \frac{480}{x} \amp = 3\\ \frac{160}{x - 8} - \frac{160}{x} \amp = 1 \quad \text{(dividing by 3)}\\ \frac{160x - 160(x - 8)}{x(x - 8)} \amp = 1\\ \frac{1280}{x^2 - 8x} \amp = 1\\ x^2 - 8x - 1280 \amp = 0 \end{align*}
    🔗
    🔗

    Subsection Solving Quadratic Equations

    A quadratic equation can be written in the standard form:
    🔗
    \begin{gather*} ax^2 + bx + c = 0 \quad \text{where } a \neq 0 \end{gather*}
    The values of \(x\) that satisfy the equation are called the roots (or solutions) of the equation, which graphically respond to th x-intercepts of the parabola. A quadratic equation has at most two real roots.
    🔗
    There are three primary algebraic methods used to solve quadratic equations, along graphical inspection.
    🔗
    Solving Quadratic equations by Factorization
    🔗
    When a quadratic equations can be easily factored, this is often the fastest method. It relies on the Zero Product Property:
    If the product of two factors is zero, then at least one of the factors must be zero (i.e., if AB = 0, then A = 0 or B = 0).
    🔗
    🔗
    1. Write the equation in standard form (\(ax^2 + bx + c = 0\)).
      🔗
      🔗
    2. Factor the quadratic expression into two linear binomials.
      🔗
      🔗
    3. Set each binomial factor equal to zero.
      🔗
      🔗
    4. Solve the resulting linear equations for \(x\text{.}\)
      🔗
      🔗
    🔗

    Example 25 .

    Solve \(x^{2} - 5x + 6 = 0\)
    🔗
    Solution.
    Solve \(x^2 - 5x + 6 = 0\) by factorization:
    🔗
    Find two numbers that multiply to \(6\) and add to \(-5\text{:}\) these are \(-2\) and \(-3\text{.}\)
    🔗
    \begin{align*} x^2 - 5x + 6 \amp = 0\\ (x - 2)(x - 3) \amp = 0 \end{align*}
    Set each factor equal to zero and solve for \(x\text{:}\)
    🔗
    \begin{align*} x - 2 = 0 \amp \quad \text{or} \quad x - 3 = 0\\ x = 2 \amp \quad \text{or} \quad x = 3 \end{align*}
    🔗
    🔗

    Example 26 .

    Solve for \(x\text{,}\) in \(3x^{2} + 10x = 8\)
    🔗
    Solution.
    Rewrite the equation in standard form \(ax^2 + bx + c = 0\text{:}\)
    🔗
    \begin{align*} 3x^2 + 10x - 8 \amp = 0 \end{align*}
    Factorise by finding two numbers that multiply to \(3 \times (-8) = -24\) and add to \(10\) (these are \(12\) and \(-2\)):
    🔗
    \begin{align*} 3x^2 + 12x - 2x - 8 \amp = 0\\ 3x(x + 4) - 2(x + 4) \amp = 0\\ (3x - 2)(x + 4) \amp = 0 \end{align*}
    Set each binomial factor equal to zero and solve for \(x\text{:}\)
    🔗
    \begin{align*} 3x - 2 = 0 \amp \quad \text{or} \quad x + 4 = 0\\ x = \frac{2}{3} \amp \quad \text{or} \quad x = -4 \end{align*}
    🔗
    🔗

    Example 27 .

    The length of a rectangular plot of land is \(3\text{ metres}\) longer than its width. If the total area of the plot is \(40\text{ m}^{2}\text{,}\) find its dimensions.
    🔗
    Solution.
    Let the width of the rectangular plot be \(w\text{ m}\text{.}\) Then the length is \((w + 3)\text{ m}\text{.}\)
    🔗
    Using the area formula \(\text{Area} = \text{Length} \times \text{Width}\text{:}\)
    🔗
    \begin{align*} w(w + 3) \amp = 40\\ w^2 + 3w - 40 \amp = 0 \end{align*}
    Factorise by finding two numbers that multiply to \(-40\) and add to \(3\) (these are \(8\) and \(-5\)):
    🔗
    \begin{align*} (w + 8)(w - 5) \amp = 0 \end{align*}
    Set each factor equal to zero:
    🔗
    \begin{align*} w + 8 = 0 \amp \quad \text{or} \quad w - 5 = 0\\ w = -8 \amp \quad \text{or} \quad w = 5 \end{align*}
    Since width must be positive, we reject \(w = -8\text{.}\) Thus, the width is \(5\text{ m}\) and the length is \(5 + 3 = 8\text{ m}\text{.}\)
    🔗
    🔗
    🔗
    Solving Quadratic equations by completing the square
    🔗
    This method transforms any quadratic equation into a perfect square quadratic equation equal to a constant, making it easy to solve by taking square roots.
    🔗
    To solve for the roots of a quadratic equation by completing square:
    🔗
    1. Ensure the leading coefficient \(a = 1\) (divide the entire equation by \(a\) if necessary).
      🔗
      🔗
    2. Move the constant term to the right side of the equation.
      🔗
      🔗
    3. Add \(\left(\frac{b}{2}\right)^2\) to both sides to complete the square on the left.
      🔗
      🔗
    4. Express the left side as a squared binomial and simplify the right side.
      🔗
      🔗
    5. Take the square root of both sides and solve for \(x\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 28 .

    Solve \(x^2 + 6x + 5 = 0\) by completing the square:
    🔗
    Solution.
    Solve \(x^2 + 6x + 5 = 0\) by completing the square:
    🔗
    Move the constant term to the right side of the equation:
    🔗
    \begin{align*} x^2 + 6x \amp = -5 \end{align*}
    Add \(\left(\frac{6}{2}\right)^2 = 9\) to both sides to complete the square:
    🔗
    \begin{align*} x^2 + 6x + 9 \amp = -5 + 9\\ (x + 3)^2 \amp = 4 \end{align*}
    Take the square root of both sides and solve for \(x\text{:}\)
    🔗
    \begin{align*} x + 3 \amp = \pm\sqrt{4}\\ x + 3 \amp = \pm 2\\ x = -3 + 2 = -1 \amp \quad \text{or} \quad x = -3 - 2 = -5 \end{align*}
    🔗
    🔗

    Example 29 .

    A school plans to construct a rectangular playground whose length is \(4\text{ metres}\) longer than its width. If the total area of the playground must be \(60\text{ square metres}\text{,}\) find the dimensions of the playground using the completing the square method.
    🔗
    Solution.
    Let the width of the rectangular playground be \(w\text{ m}\text{.}\) Then the length is \((w + 4)\text{ m}\text{.}\)
    🔗
    Using the area formula \(\text{Area} = \text{Length} \times \text{Width}\text{:}\)
    🔗
    \begin{align*} w(w + 4) \amp = 60\\ w^2 + 4w \amp = 60 \end{align*}
    Complete the square by adding \(\left(\frac{4}{2}\right)^2 = 4\) to both sides:
    🔗
    \begin{align*} w^2 + 4w + 4 \amp = 60 + 4\\ (w + 2)^2 \amp = 64 \end{align*}
    Take the square root of both sides and solve for \(w\text{:}\)
    🔗
    \begin{align*} w + 2 \amp = \pm\sqrt{64}\\ w + 2 \amp = \pm 8\\ w = -2 + 8 = 6 \amp \quad \text{or} \quad w = -2 - 8 = -10 \end{align*}
    Since physical width must be positive, we reject \(w = -10\text{.}\) Thus, the width of the playground is \(6\text{ m}\) and the length is \(6 + 4 = 10\text{ m}\text{.}\)
    🔗
    🔗
    🔗
    Solving Quadratic equations Using quadratic formula
    🔗
    The universal method that works for any quadratic equation,whether it can be easily factored or not. It is derived from completing the square. The formula is:
    🔗
    \begin{gather*} x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \end{gather*}
    The term inside the square root, \(\Delta = b^2 - 4ac\text{,}\) is called the Discriminant, which determines the nature of the roots:
    🔗
    • \(\Delta > 0\text{:}\) Two distinct real roots.
      🔗
      🔗
    • \(\Delta = 0\text{:}\) One repeated real root (a perfect square).
      🔗
      🔗
    • \(\Delta < 0\text{:}\) Two complex (non-real) roots.
      🔗
      🔗
    🔗
    Derivation of the quadratic formula
    🔗
    The quadratic formula can be universally derived for any quadratic equation by applying the method of completing the square to the standard form.
    🔗
    The General Quadratic Equation
    🔗
    Start with the standard form of a quadratic equation, where \(a \neq 0\text{:}\)
    🔗
    \begin{gather*} ax^2 + bx + c = 0 \end{gather*}
    Step-by-Step Derivation
    🔗
    1. Make the leading coefficient equal to 1: Divide every term in the equation by \(a\text{:}\)
      🔗
      \begin{gather*} x^2 + \frac{b}{a}x + \frac{c}{a} = 0 \end{gather*}
      🔗
    2. Isolate the variable terms: Move the constant term \(\frac{c}{a}\) to the right-hand side of the equation:
      🔗
      \begin{gather*} x^2 + \frac{b}{a}x = -\frac{c}{a} \end{gather*}
      🔗
    3. Complete the square on the left side: Take the coefficient of \(x\text{,}\) which is \(\frac{b}{a}\text{,}\) divide it by \(2\) to get \(\frac{b}{2a}\text{,}\) and square it to get \(\frac{b^2}{4a^2}\text{.}\)
      🔗
      Add this value to both sides of the equation:
      🔗
      \begin{gather*} x^2 + \frac{b}{a}x + \frac{b^2}{4a^2} = \frac{b^2}{4a^2} - \frac{c}{a} \end{gather*}
      🔗
    4. Simplify both sides: Express the left side as a squared binomial and combine the fractions on the right side using the common denominator \(4a^2\text{:}\)
      🔗
      \begin{align*} \left(x + \frac{b}{2a}\right)^2 \amp = \frac{b^2}{4a^2} - \frac{4ac}{4a^2}\\ \left(x + \frac{b}{2a}\right)^2 \amp = \frac{b^2 - 4ac}{4a^2} \end{align*}
      🔗
    5. Take the square root of both sides: Apply the square root property, including both the positive and negative roots (\(\pm\)):
      🔗
      \begin{gather*} x + \frac{b}{2a} = \pm \sqrt{\frac{b^2 - 4ac}{4a^2}} \end{gather*}
      Simplify the denominator on the right side since \(\sqrt{4a^2} = 2a\text{:}\)
      🔗
      \begin{gather*} x + \frac{b}{2a} = \frac{\pm \sqrt{b^2 - 4ac}}{2a} \end{gather*}
      🔗
    6. Isolate \(x\text{:}\) Subtract \(\frac{b}{2a}\) from both sides and combine the terms under the common denominator:
      🔗
      \begin{align*} x \amp = -\frac{b}{2a} \pm \frac{\sqrt{b^2 - 4ac}}{2a}\\ x \amp = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \end{align*}
      🔗
    🔗
    Result
    🔗
    This completes the derivation, yielding the universal Quadratic Formula:
    🔗
    \begin{gather*} x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \end{gather*}

    Example 30 .

    Solve \(2x^{2} + 5x - 3 = 0\)
    🔗
    Solution.
    Solve \(2x^2 + 5x - 3 = 0\) using the quadratic formula:
    🔗
    Identify the coefficients \(a = 2\text{,}\) \(b = 5\text{,}\) and \(c = -3\text{.}\)
    🔗
    Substitute these values directly into \(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\text{:}\)
    🔗
    \begin{align*} x \amp = \frac{-5 \pm \sqrt{5^2 - 4(2)(-3)}}{2(2)}\\ \amp = \frac{-5 \pm \sqrt{25 + 24}}{4}\\ \amp = \frac{-5 \pm \sqrt{49}}{4}\\ \amp = \frac{-5 \pm 7}{4} \end{align*}
    Solve for both cases:
    🔗
    \begin{align*} x = \frac{-5 + 7}{4} = \frac{1}{2} \amp \quad \text{or} \quad x = \frac{-5 - 7}{4} = -3 \end{align*}
    🔗
    🔗

    Example 31 .

    Solve by quadratic formula: \(x^{2} + 6x + 5 = 0\)
    🔗
    Solution.
    Solve \(x^2 + 6x + 5 = 0\) using the quadratic formula:
    🔗
    Identify the coefficients \(a = 1\text{,}\) \(b = 6\text{,}\) and \(c = 5\text{.}\)
    🔗
    Substitute these values directly into \(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\text{:}\)
    🔗
    \begin{align*} x \amp = \frac{-6 \pm \sqrt{6^2 - 4(1)(5)}}{2(1)}\\ \amp = \frac{-6 \pm \sqrt{36 - 20}}{2}\\ \amp = \frac{-6 \pm \sqrt{16}}{2}\\ \amp = \frac{-6 \pm 4}{2} \end{align*}
    Solve for both cases:
    🔗
    \begin{align*} x = \frac{-6 + 4}{2} = -1 \amp \quad \text{or} \quad x = \frac{-6 - 4}{2} = -5 \end{align*}
    🔗
    🔗
